# Smart Dual-Axis Solar Tracking System

This repository contains the implementation of a smart dual-axis solar tracking system developed as a graduation project (2026).

The system uses a hybrid control approach combining solar position calculations with real-time sensor feedback to maintain optimal panel alignment. It also includes environmental monitoring and IoT-based visualization.

For full system design, methodology, and analysis, refer to the project report.
